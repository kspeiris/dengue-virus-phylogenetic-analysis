# Dengue Virus Phylogenetic Analysis

This repository contains the dataset, workflow, results, and documentation for the phylogenetic analysis of Dengue virus genomes. The analysis is performed on 28 human-derived complete genomes isolated from blood samples across Asia using the Galaxy platform, MAFFT for sequence alignment, and IQ-TREE for Maximum Likelihood tree construction.

## Folder Structure

- `assignment/`: Core assignment brief and documents.
- `data/`: Original and aligned sequence data (FASTA).
- `docs/`: Markdown files for each section of the phylogenetic analysis report (Introduction, Methods, Results, Discussion, Conclusion).
- `figures/`: Relevant figures and screenshots.
- `iqtree/`: IQ-TREE outputs for bootstrap replicates (100 and 1,000 runs) and comparison notes.
- `results/`: Formatted markdown files for alignment statistics, IQ-TREE parameters, tree interpretations, and discussion answers.
- `references/`: Bibliographic references and literature assets.
- `workflow/`: Rebuildable Galaxy workflow files.
